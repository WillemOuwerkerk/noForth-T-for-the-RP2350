<h1 align="center"> Using the noForth t metacompiler</h1>

**Shortest LED flasher**
- Start Win32Forth
- Select the folder: Flasher
- include T-meta-sep11.f
- include blink-3a.f
    - Type **-** key
    - Type **.** key
          
The blinker UF2 file is ready with the current date in the
filename, example: blinker 260921.uf2


Note the meta compiler uses these files:
- noForth-T-asm-M33.f
- RP2040-DAS.f
- T-meta-sep11.f
- blink-3a.f
